# Quick Reference: Profile Management

## Profile Picture Upload

### How to Upload
1. Go to **Users** page
2. Click **Edit** button on user card
3. Click **Upload** or **Change** button
4. Select image file
5. Wait for upload to complete

### Requirements
- **Formats**: JPEG, PNG, GIF, WEBP, AVIF
- **Max Size**: 1 MB (auto-compressed if larger)
- **Max Resolution**: 1920x1080
- **Filename**: English letters and numbers only

### How to Remove
1. Open user edit dialog
2. Click **Remove** button
3. Picture deleted immediately

## Mobile Number Management

### How to Add/Update
1. Go to **Users** page
2. Click **Edit** button on user card
3. Enter mobile number in **Mobile Number** field
4. Click **Save**

### How to Remove
1. Open user edit dialog
2. Clear the **Mobile Number** field
3. Click **Save**

## Where Information Appears

### Profile Pictures
- User cards (large avatar)
- Header menu (small avatar)
- User dropdown menu

### Mobile Numbers
- User cards (with phone icon)
- User dropdown menu (logged-in user only)

## Common Issues

| Issue | Solution |
|-------|----------|
| Upload fails | Check file size and format |
| Poor quality | Use higher quality source image |
| Won't save | Click Save button, check permissions |
| Doesn't appear | Refresh page (Ctrl+F5) |

## Tips
- Use clear, professional photos
- Keep mobile numbers up to date
- Refresh page if changes don't appear
- Contact admin for help

## Keyboard Shortcuts
- **Tab**: Navigate between fields
- **Enter**: Save form
- **Esc**: Close dialog
